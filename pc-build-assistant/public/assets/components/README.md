# Component Icons

Place your custom component images in this directory with the following names:

- `cpu.png` - CPU icon
- `gpu.png` - GPU icon
- `motherboard.png` - Motherboard icon
- `ram.png` - RAM icon
- `storage.png` - Storage icon
- `psu.png` - PSU icon

## Recommended Specifications

- Format: PNG with transparency
- Size: 256x256 pixels (will be scaled down)
- Style: Consistent across all icons
- Background: Transparent

## Example Sources

You can find suitable icons from:
- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)
- [The Noun Project](https://thenounproject.com/)

Make sure to respect licensing requirements for any icons you use.
