# Manufacturer Logo Placeholders

Place your manufacturer logo images in this folder. The images should be named after the manufacturer (lowercase, hyphens for spaces).

## Image Specifications

- **Format**: PNG (with transparency) recommended
- **Size**: 200x200 pixels (will be displayed at 140x140)
- **Background**: Transparent or white
- **Style**: Logo only, no text borders

## Fallback Behavior

If a logo image is not found or fails to load, the component card will display a fallback emoji icon based on the component type:
- CPU: 🖥️
- GPU: 🎮
- Motherboard: 🔌
- RAM: 💾
- Storage: 💿
- PSU: ⚡
